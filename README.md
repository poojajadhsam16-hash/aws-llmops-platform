# AWS Cloud Platform + AI/LLMOps

Production-style RAG platform built on AWS.

## Project Goal

Build and operate a production-style Retrieval-Augmented Generation
(RAG) platform using:

- AWS
- Terraform
- Docker
- Kubernetes
- Amazon EKS
- Amazon ECR
- FastAPI
- GitHub Actions
- CloudWatch
- IAM
- LLMOps

## Architecture

The platform will eventually include:

User
→ ALB
→ EKS
→ FastAPI RAG Service
→ Vector Search
→ LLM

Supporting services:

- Amazon S3
- IAM
- CloudWatch
- ECR
- Terraform
- GitHub Actions
